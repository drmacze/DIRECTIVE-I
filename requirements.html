SYSTEM COMPATIBILITY

Requirements.

Check the minimum hardware baseline before entering DIRECTIVE I. Vibrant Visuals must be enabled for the intended visual experience.

Game Version

Vibrant Visuals

Minecraft Bedrock with Vibrant Visuals enabled is required for the intended graphics configuration.

Mobile Graphics

Modern Mobile GPU

Android baseline: Adreno 640 / Snapdragon 855-class or a supported Mali / MediaTek 1000-series-class GPU. iOS baseline: A12 Bionic or newer.

Memory

4 GB RAM Minimum

At least 4 GB of system memory is required. More memory is recommended when using high-resolution assets or additional resource packs.

Storage

10 GB Free Space

Keep a minimum of 10 GB free storage for the world, project assets, cache, and future content updates.

PC Graphics

DirectX 12 FL11

For Windows PCs, a GPU supporting DirectX 12 Feature Level 11 is recommended for the intended rendering path.
